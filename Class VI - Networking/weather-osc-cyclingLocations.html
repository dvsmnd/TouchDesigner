    Setting up TouchDesigner
    1. Browsers can't send UDP, so run the small bridge next to this file: node bridge.js
    2. Open http://localhost:8080 (or this file), then press Connect bridge.
    3. In TouchDesigner add an OSC In CHOP and set its Network Port to the port above (7000 is the default).
    4. Each ticked number arrives as its own channel, named after its address. The location name is text, so read it with an OSC In DAT. The same goes for "One message, all numbers as arguments".
    5. To react to a location change, watch the location number channel (it steps 0, 1, 2 ...) or use the progress channel as a ramp from 0 to 1 between switches.
